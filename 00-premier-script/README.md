# 01 — Votre premier script Python utile
Combien avez-vous dépensé au restaurant ce mois-ci ? Et en courses ? Dans cette vidéo, vous écrivez un vrai script Python qui répond à ces questions à partir d'un fichier CSV de 247 dépenses.

Pas de théorie abstraite : on part d'un fichier, on écrit le code ensemble dans VS Code, on provoque une erreur volontairement, et on la corrige.

Code et fichier CSV : [LIEN GITHUB DU MODULE 1]

Ce que vous allez apprendre
- Lire un fichier CSV avec le module csv (with open, DictReader)
- Comprendre pourquoi "13.16" n'est pas 13.16 : un texte (str) contre un nombre (float)
- Filtrer des lignes avec une condition
- Regrouper des montants par catégorie avec un dictionnaire
- Afficher un résultat lisible avec les f-strings et le trier avec sorted()

## Notions couvertes

Variables · Boucles · Conditions · Dictionnaires · Conversion de types · f-strings
